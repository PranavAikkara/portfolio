Anthropic lets Claude negotiate real deals between employees, closes $4,000 in trades
12,049 Likes

Anthropic just ran a real marketplace where AI agents negotiated on behalf of humans, no human involvement once it started. Think Craigslist, but Claude handles all the haggling for you.

Here is how it worked: Claude interviewed each person, learned what they wanted to buy or sell, then went off and negotiated completely on its own. The results were solid:

  • 186 deals closed across 500+ listed items, totaling over $4,000
  • 46% of participants said they would pay for a service like this
  • One agent, based on a passing mention of skiing, bought someone the exact snowboard they already owned

The big finding: model quality matters more than your instructions. Telling Claude to "negotiate hard" barely moved the needle. But Opus agents consistently beat Haiku agents on price, and the people with weaker agents never noticed.

That last part is the real story. If AI agents start handling real transactions, you could be losing money without knowing it, simply because your agent is cheaper.

Open-source headless browser Obscura loads pages 6x faster than Chrome with built-in stealth
7,693 Likes

Headless Chrome is a beast. It eats 200MB of memory per instance, takes 2 seconds to start, and ships as a 300MB binary. When you're running dozens of AI agents or scraping at scale, that adds up fast.

Meet Obscura, a new open-source headless browser built in Rust. It runs real JavaScript, speaks the same protocol Chrome uses, and fits in a single 70MB binary with no Chrome or Node.js needed.

The numbers:

  • Memory: 200MB down to 30MB
  • Page load: 500ms down to 85ms
  • Startup: 2 seconds down to instant
  • Built-in stealth: randomized fingerprints, 3,520 tracker domains blocked, navigator.webdriver hidden

The best part? It's a drop-in replacement for Puppeteer and Playwright. Zero code changes. Just point your existing scripts at Obscura's WebSocket server and go. It also converts pages directly to Markdown, which is handy when feeding content into an AI pipeline.

Karpathy's Claude coding rules hit 82K GitHub stars with one config file
7,266 Likes

You know how AI coding tools sometimes just... run with a bad assumption and write 800 lines you never asked for? That's the exact problem this fixes.

A single CLAUDE.md file just hit #1 on GitHub trending with 91k stars. It's based on Andrej Karpathy's observations about where AI coding tools go wrong. You drop it into your project, and Claude Code reads it as instructions before touching anything.

Four rules it enforces:

  • Think before coding - ask clarifying questions instead of guessing silently
  • Simplicity first - no extra abstractions, no features you didn't ask for
  • Surgical edits only - touch nothing outside the task, ever
  • Goal-driven execution - define what success looks like, then loop until it's verified

Install it in one line: curl -o CLAUDE.md https://raw.githubusercontent.com/forrestchang/andrej-karpathy-skills/main/CLAUDE.md

Works with Cursor too. Zero dependencies. Just a text file that makes your AI assistant actually listen.
