~/principles

What I optimise for

01

Traceability over magic

If you can't point at where an answer came from, it's a liability, not a feature.

02

Evals before vibes

Build the ruler before you trust the result. A demo that dazzles proves nothing.

03

Latency is a feature

In voice especially. Speed isn't polish, it's whether the thing is usable at all.

04

Small models, narrow jobs

Stop paying frontier prices for a task a fine-tuned small model can nail.

05

Fix the data first

Half of what looks like a model problem is a structure problem in disguise.

06

Write it down

The system you can't explain is the system that pages you at 3am.
