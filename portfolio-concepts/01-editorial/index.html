01 / Selected casework

Four systems, written up the way I'd
hand them to the next engineer.

Vectorless retrieval over enterprise documents

2025

A retrieval layer that answers from large document sets without a vector store or an embedding index to babysit. The model reasons over a structured table of contents and pulls only the passages it needs, so answers stay traceable to a page rather than to a fuzzy similarity score.

RetrievalLLM routingCitations

Voice agents for field operations

2025

A telephony-grade voice agent that takes a call, understands intent over a noisy line, and completes a task end to end. The hard part was never the speech model, it was the turn-taking, the barge-in, and recovering gracefully when the caller says something the script never imagined.

ASR / TTSLatencyDialogue state

Document ingestion that tolerates the real world

2024

An ingestion pipeline for the documents nobody wants to parse: scanned forms, merged cells, three languages on one page. It normalises structure first and content second, so everything downstream gets clean text instead of a guess.

OCRParsingPipelines

Fine-tuning small models for a narrow job

2024

When a frontier model was overkill and slow, I fine-tuned a smaller one to do exactly one task well. The write-up covers the data curation, where the synthetic examples helped and where they quietly poisoned the set, and how I knew when to stop.
